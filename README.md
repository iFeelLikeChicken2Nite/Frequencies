# Frequencies
## A modern, stylish internet radio player. Simple, yet powerful. Decline the algorithm, and rediscover radio.

<img width="1467" height="1002" alt="Screenshot_20261018_182004" src="https://github.com/user-attachments/assets/7e057a12-ba5b-4a46-96ea-c40dfbf6b15e" />

Frequencies is a stylish internet radio player that is simple on the surface, but built on a powerful framework which allows for a lot of room for customization and options. It sets out to provide a rich, unified, modern day feature set for making listening to the radio as user friendly as streaming on Spotify, but more flexible than most other radio streaming applications.

## Features that set Frequencies apart:

On top of your typical radio apps that allow you to stream from URLs and browse radio station directories, Frequencies allows for broader capabilities, such as...

* Ability to create custom stations from local files, YouTube stations, Twitch streams, and iBroadcast libraries
* Tags system for easily queuing your desired stations
* Built in Shazam
* A reguarly updated list of recommended radio stations that are hand picked by me, a human
* Per station equalizer options
* Volume equalization across stations
* Optional, immersive static to bridge the silent gap between stations
* Song logging based on Shazam recognition
* A built in, experimental web browser designed to let you easily "steal" an embedded audio player's stream URL from a list 
* Ability to change station's displayed name and associated artwork
* Easy, modern sharing options
* Winamp skin support
* Built in Project M visualizers
* Compatibility with over 10 popular radio apps

...and coming down the line, nearly full feature parity with an Android port, including Android Auto compatibility (I would love to include iOS, but that has costs I can't afford, I am thinking of building a solution for forwarding audio to iOS etc though)
